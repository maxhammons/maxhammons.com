# maxhammons.com

Static copy of the portfolio site, rebuilt from the Adobe Portfolio export so it
can be hosted anywhere (target: GitHub Pages with the existing custom domain).

## Layout

| Path | What it is | Edit it? |
|---|---|---|
| `raw/` | Pristine `wget` mirror of the live Adobe site, taken 2026-09-03. | Never. |
| `theme/site.css` | The design system: fonts, palette, type scale, sticky nav, link hover, grids, buttons. Loaded after the exported Adobe CSS on every page and overrides it. | Yes, this is where design changes go. |
| `fonts/` | Self-hosted Proxima Nova (Light 300, Regular 400, Semibold 600, Bold 700) plus the mono used for code samples. | Only to swap fonts. |
| `content/manifest/` | Per-page text and image inventory, generated by `make_manifest.py`. Input for the review agents. | Regenerate, don't edit. |
| `content/pages/` | Per-page JSON from the review pass: alt text for every image, copy fixes as find/replace, open questions. | Yes, hand-edit alt text or add copy fixes here. |
| `content/copy-changelog.md` | Every copy edit the build applied, with the reason. | Generated. |
| `content/voice/` | Max's resume text, used as the voice reference during the copy review. | Reference only. |
| `build.py` | Builds `site/` from all of the above. | Yes. |
| `site/` | The finished site. Disposable; rebuilt by `build.py`. | Never by hand. |

## Build and preview

```
python3 build.py
cd site && python3 -m http.server 8765
open http://localhost:8765/
```

## What the build does

1. Copies every image the pages reference into `site/assets/` (downloads any the mirror missed).
2. Keeps four of the exported Adobe stylesheets (project, home, sandbox, reel) and links `theme/site.css` after them on every page.
3. Replaces the Adobe Typekit loader with local `@font-face` rules.
4. Removes the back-to-top links.
5. Marks intros longer than 360 characters with `is-long`, which the CSS lays out as two columns above the first image.
6. Applies alt text and copy edits from `content/pages/*.json`.
7. Writes every page as `slug/index.html`, plus `CNAME`, `.nojekyll`, and a `404.html`.

## Known open items

- Site is 2.0 GB of images. GitHub Pages caps a published site at 1 GB. Decision deferred (trim to 1920px, or host on Cloudflare Pages).
- Proxima Nova web files came from the Adobe Fonts kit. Self-hosting needs a Proxima Nova web license.
- The Reel page is a placeholder: a background GIF and a "Click Here" button that links back to the portfolio.
