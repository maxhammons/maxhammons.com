# maxhammons.com

Static portfolio site, originally exported from Adobe Portfolio and now self-contained: its own
stylesheet, one small script, no hosted-theme runtime. Hosted on GitHub Pages with the existing
custom domain.

## Layout

| Path | What it is | Edit it? |
|---|---|---|
| `raw/` | Pristine `wget` mirror of the original site, taken 2026-09-03. The build's source for page markup and images. | Never. |
| `theme/base.css` | The rules of the exported theme that the pages still use (merged from its four per-layout stylesheets; rules one layout needs are scoped to that layout's `<html>` class). | Rarely; design changes go in `site.css`. |
| `theme/site.css` | The design system: fonts, palette, type scale, sticky nav, link hover, grids, buttons, intro box, closing call to action, blurred image previews. Served after `base.css` in the same file and overrides it. | Yes, this is where design changes go. |
| `theme/site.js` | The only script: page transitions, prefetch, phone menu, blurred previews, footer year. | Yes. |
| `fonts/` | Self-hosted Proxima Nova (Light 300, Regular 400, Semibold 600, Bold 700) plus the mono used for code samples. | Only to swap fonts. |
| `content/manifest/` | Per-page text and image inventory, generated by `make_manifest.py`. Input for the review agents. | Regenerate, don't edit. |
| `content/pages/` | Per-page JSON: alt text for every image, copy fixes as find/replace, captions to keep (`keep_captions`), the page intro (`intro`, replaces the exported one), open questions. | Yes, hand-edit alt text, intros, copy fixes, or list a caption to keep here. |
| `content/copy-changelog.md` | Every copy edit the build applied, with the reason. | Generated. |
| `content/voice/` | Max's resume text, used as the voice reference during the copy review. | Reference only. |
| `optimize.py` | Image conversion used by the build: every raster becomes WebP, animated GIFs become animated WebP, and each image gets a 16px preview. Cached in `raw/derived/`. | Only to change quality settings. |
| `build.py` | Builds `site/` from all of the above. | Yes. |
| `site/` | The finished site. Disposable; rebuilt by `build.py`. | Never by hand. |

## Build and preview

```
python3 build.py
cd site && python3 -m http.server 8765
open http://localhost:8765/
python3 qa.py        # in another terminal, with the server running
```

## What the build does

1. Copies every image the pages and `theme/base.css` reference into `site/assets/` (downloads any the mirror missed).
2. Serves `theme/base.css` + `theme/site.css` as one stylesheet, and `theme/site.js` as the only script. Removes the hosted theme's runtime (bundle, settings, translations, lightbox templates), its editor attributes and unused `js-`/`e2e-` classes, and the Typekit loader. Google Analytics loads after the page has.
3. Images: real `src`/`srcset`/`sizes` with native lazy loading (the first project image and the first gallery row load at once), and a blurred 16px preview on each image box that clears when the image loads on screen. Image grids are justified rows in CSS.
4. Removes the back-to-top links.
5. Replaces each intro with `intro` from `content/pages/*.json` when there is one, and marks intros longer than 360 characters with `is-long`. On wide screens every intro sits in a box eight lines tall on the homepage's three columns, filling the first column before running into the next (long intros get twelve lines below 1200px and nine up to 1365px, so none spills out); on tablets `is-long` intros run as two columns, on phones one.
6. Applies alt text and copy edits from `content/pages/*.json`, then removes every one-line image caption a page does not list in `keep_captions`. Stamps the footer copyright with the build year; `site.js` keeps it current between builds.
6b. Adds "Let's work together" (email) and Resume above the footer of every page that has one, and Next project to project page footers (homepage or sandbox order, wrapping round).
6c. Converts images to WebP (animated GIFs to animated WebP), preloads the two main fonts, marks images `decoding="async"`, and prunes unreferenced assets. First run takes about a minute per 1,000 images; later runs use the cache.
7. Writes every page as `slug/index.html`, plus `CNAME`, `.nojekyll`, and a `404.html`.

## Page transitions

`theme/site.js` + the last section of `theme/site.css`. Clicking a gallery thumbnail zooms it
edge to edge (image, white panel, red title and strike line grow together), holds until the
project page underneath has loaded, then the strike erases like a progress bar and everything
fades off together (0.75s, `--vt-t` scales it). Logo, Home, back button or swipe play the exact
reverse into the thumbnail, scrolled into view first. Hovering a thumbnail runs the first beats
the same way: the white panel and title fade in, then the strike draws; leaving reverses it.
Built on cross-document View Transitions with full-size twins of the thumbnail parts on the
project page, so the browser interpolates the geometry itself and the title is crisp text
(Chrome 126+, Safari 18.2+, Firefox 144+); other browsers get a plain fade. Loading ahead of the click: Chrome and Edge prerender a project page on hover (speculation
rules, thumbnails and Next project); every browser prefetches its HTML and first image on hover or touch; once a gallery is
idle, all project pages' HTML is fetched at low priority in top-to-bottom order, plus the first
image of the covers on screen; each project page preloads its first image from the head.
`python3 qa.py` verifies both directions.

## Hosting

GitHub Pages, deployed by `.github/workflows/pages.yml` from `site/` on every push to `main`.
Custom domain `maxhammons.com` via `site/CNAME`; DNS stays at Squarespace (A records to
GitHub's IPs for the apex, CNAME `www` to `maxhammons.github.io`).

Image variants wider than 2000px and the full-size originals are dropped by the build
(`MAX_IMAGE_WIDTH` in `build.py`) so the published site stays under the 1 GB Pages cap.
The originals are still in `raw/` on Max's Mac (ignored by git).
